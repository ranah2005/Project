# Paradise Nursery

Paradise Nursery is a small online plant shop built with React, Vite, Redux Toolkit, and React Router. It gives customers an easy way to browse houseplants, add them to a cart, and adjust quantities before checkout.

## Features
- Browse a curated selection of houseplants by category
- Add plants to the shopping cart
- Increase or decrease item quantities in the cart
- Remove items or clear them entirely
- View total plant count and total order value
- Continue shopping or move to checkout from the cart page

## Tech Stack
- React
- Vite
- Redux Toolkit
- React Router
- Plain CSS
